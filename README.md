# Phantombite_Pandora

Planeten-Mod der Phantombite Mod Suite für Space Engineers: der Planet **Pandora** (Planetendefinition,
Planetendaten, Umgebungsmodelle und Texturen). Reiner Daten-Mod, kein Skript.

Zum Spawnen an einer festen Position in der Welt dient `Phantombite_PlanetSpawner` (der Planet wird dort mit
`Enable=true` und Koordinaten eingetragen).
